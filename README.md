# My Personal Journal

A premium personal journal and blog featuring responsive styling, dynamic weather graphing, markdown support, tag filtering, and dual database support (SQLite/PostgreSQL).

## Features

- **Styling**: Sleek light/dark mode with dynamic HSL variables and fluid layout.
- **Weather Widget**: Interactive Canvas chart showing 24h temperature curves, geocoding city search, and real-time conditions.
- **Markdown**: Full markdown parsing for headers, lists, quotes, and code blocks.
- **Search & Filters**: Instantly query titles, content, or filter posts by tag.
- **Storage**: Multi-environment compatibility with SQLite (local development) and PostgreSQL (production).
- **Security**: Optional admin credential protection for writing/editing/deleting posts.

## Getting Started

```bash
npm install
npm start
```
